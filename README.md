# Patmos Tourism Review Analysis

This repository publishes four browser-based research interfaces:

- Analytic dashboard
- Quotable anthology
- Thematic reading dossiers
- Chapter graphs

The public files contain pseudonymous review IDs, quotations, ratings, platform labels, and analytic codes used by the interfaces. They do not contain the original Excel workbooks, reviewer usernames, reviewer locations, translation checkpoints, or bulk review-level source files.

## GitHub Pages

Publish this repository from the `main` branch and the repository root. The landing page is `index.html`.

## Data availability

The original and intermediate datasets are intentionally retained outside this public repository.
